선생님 (방 만들기)

빙고 단어를 입력하고 방을 개설합니다. 교실 TV에 QR코드와 단어 추첨기를 띄우고 학생들의 빙고 현황을 실시간으로 확인합니다.

🙋‍♂️

학생 (방 입장하기)

선생님이 알려준 방 코드(4자리)와 내 이름을 입력하고 나만의 빙고판을 만들어 게임에 참여합니다.

인터넷/DB 없이 혼자 쓰시나요? 교실 화면 하나만 띄워놓고 클릭하며 진행하는 단독 모드도 지원합니다.

✏️ 2. 빙고 단어 목록 입력
